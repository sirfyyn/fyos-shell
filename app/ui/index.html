Runner

Ein entfernter Runner läuft auf einem anderen Rechner (eigenes Netz oder Tunnel). Die Anwendung bringt keinen mit. Das Token liegt im Tresor des Systems, nie in einer Datei. Umschalten geht im Chat-Fenster oben in der Seitenleiste.

    Runner hinzufügen

    z. B. der Tailscale-Name, damit der Runner auch unterwegs erreichbar ist

    Lokaler Runner (optional)

    Auf diesem Rechner kann die Anwendung ein Programm als Runner starten und beaufsichtigen. Sie bringt keines mit: hier steht der absolute Pfad eines Programms, das den Vertrag in der README erfüllt. Port und Token vergibt die Anwendung bei jedem Start neu.
